# 佣金计算器

房产中介佣金计算工具（CLI + 图形界面）。输入房源信息、支付金额和角色归属，自动完成6步分账计算并输出每笔明细。

## 功能

- 两种房源类型：租赁 / 买卖
- 两种计算视角：成交人（我店成交它店房源）/ 房源方（它店成交我店房源）
- 6步计算流程：理房通平台费 → 角色业绩拆分 → 实收佣金 → 德佑平台服务费 → 进店实收 → 业务员应发
- 多业务员拆分：当本店有2个以上业务员分别持有不同角色时，按角色比例分别计算每人应发佣金
- 买卖房源3%平台实勘费自动处理，不参与分账
- 成交人兼任房源方角色时自动调整占比
- 8种支付方式的快捷选择
- PySide6 图形界面（向导式5步导航，实时费率预览，一键复制结果）

## 业务规则

### 角色占比

| 角色 | 租赁 | 买卖 |
|------|------|------|
| 录入人 | 10% | 10% |
| 维护人 | 10% | 15% |
| 实勘人 | 10% | 2% |
| 钥匙人 | 5% | 5% |
| 证件人 | — | 5% |
| 平台实勘 | — | 3%（平台收取，不参与分账） |
| 客源成交人 | 60% | 60% |

> 成交人占比 = 100% - 其他角色占比之和。当部分角色由成交人兼任时，成交人占比自动增大。

### 支付通道费（理房通）

| 支付方式 | 费率 |
|----------|------|
| 微信小程序 | 0.65% |
| 微信APP | 0.65% |
| 微信扫码 | 0.3% |
| 支付宝APP | 0.3% |
| 支付宝扫码 | 0.3% |
| 快捷支付 | 0.4% |
| 银联线上支付 | 0.55% |
| 京东白条 | 0.3% |

### 提成规则

- 德佑平台服务费：实收佣金 × 8%
- 业务员提成：进店实收 × 50%

## 安装

```bash
uv sync
```

## 使用

### 命令行

```bash
uv run commission
```

### 图形界面

```bash
uv run commission-gui
```

交互流程（CLI / GUI 通用）：
1. 选择房源类型（租赁/买卖）
2. 选择计算视角（成交人/房源方）
3. 输入支付金额和方式（数字快捷选择）
4. 选择角色归属（全部属于本店 / 逐个选择 / 全部不属于本店）
5. 选择是否按业务员拆分佣金，为每个角色指定业务员姓名
6. 输出完整6步计算明细 + 各业务员拆分明细

## 开发

uv run python -m commission  # CLI入口
